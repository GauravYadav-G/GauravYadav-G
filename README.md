### ✦ About Me

I am a **Creative Developer & Full-Stack Engineer** focused on digital craftsmanship at the intersection of aesthetic design, interactive physics, and resilient system architecture.

- 🎨 **Creative Engineering**: Building bespoke, award-caliber web experiences with 60fps micro-animations, WebGL/GLSL shaders, procedural simulation canvases, and kinetic typography.
- ⚡ **Modern Web Systems**: Engineering robust, component-driven web applications and scalable backends using TypeScript, React 19, Next.js, and Python.
- 🔬 **Current Pursuits**: Real-time generative WebGL shaders, Chladni cymatics / acoustic resonance, and agentic AI tools.
